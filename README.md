# ESP32 Game Boy Pokémon Trading & Captive Portal 🎮⚡

[ English ](#esp32-game-boy-pokémon-trading--captive-portal-) • [ Español ](#esp32-game-boy-pokémon-trading--portal-cautivo--versión-en-español)

---

Autonomous ESP32 port of the [Flipper-Zero-Game-Boy-Pokemon-Trading](https://github.com/kbembedded/Flipper-Zero-Game-Boy-Pokemon-Trading) project by **KBEmbedded** (specifically optimized for the compact **ESP32-S3 SuperMini** board).

Enables transferring, receiving, and modifying **Generation I** (Red / Blue / Yellow) and **Generation II** (Gold / Silver / Crystal) Pokémon over a physical Game Boy Link cable, controlled wirelessly from any smartphone or PC via a **standalone Wi-Fi Captive Portal** with no internet connection or external apps required.

---

## 🌟 Key Features

- **Dual Trade Workflow**:
  - **⚡ Injector / Outgoing**: Create or pick Pokémon with customizable moves, level, nickname, max IVs/EVs, shininess, and held items (Gen II), plus instant presets (Gengar, Machamp, Alakazam, Golem, Steelix, Scizor, Mew, Celebi).
  - **📥 Receiver & Modifier**: Captures incoming Pokémon sent by the Game Boy into the ESP32's RAM, inspects its held item, attacks, and stats on the *"Received"* tab, lets you edit them, and queues it back for return trading.
- **Trade Table Synchronization Notice (`in_table`)**:
  - If you configure a Pokémon while the Game Boy is already seated at the Cable Club trade table, the web UI notifies you to press **B** and sit down again so the console fetches the fresh 441-byte trade block.
- **Embedded Monochrome Sprites (PROGMEM)**:
  - All 252 original Pokémon sprites (crafted by [ProteanReverie](https://github.com/ProteanReverie) for the Flipper Zero project) are compiled directly into the ESP32's internal Flash memory, loading instantly and working 100% offline.
- **Dual-Core FreeRTOS Architecture**:
  - **Core 0**: Wi-Fi SoftAP (`GB-PokeTrader`), Captive DNS (port 53), Asynchronous Web Server, and WebSockets.
  - **Core 1**: Ultra-high-speed GPIO interrupt-driven SPI Slave driver dedicated exclusively to the Game Boy Link protocol (~8 kHz), completely immune to Wi-Fi jitter.
- **Hardware RGB Status LED (GPIO 48)**:
  - The onboard WS2812 RGB LED on the ESP32-S3 SuperMini mirrors the exact status colors of the web dashboard in real time for instant diagnostic feedback.

## 🔌 Wiring, Multimeter Testing & Soldering

> [!CAUTION]
> **NEVER TRUST INTERNAL WIRE COLORS!**  
> Third-party Game Boy Link cables (AliExpress, Amazon, or retro game stores) use completely random internal wire colors depending on factory batches.  
> **You MUST map each wire using a multimeter (tester) in continuity mode before soldering.**

### 1. Game Boy Link Cable Pinout

Looking directly into the front connector (female or male) of the Link Cable:

```
       _____/-----\_____
      |  1     3     5  |
      |  2     4     6  |
      \_________________/
```

| GB Connector Pin | Signal Name | ESP32-S3 SuperMini Pin | Function |
|:---:|:---:|:---:|:---|
| **Pin 1** | **VCC (+5V)** | *Do not connect (cut / insulate)* | Console power (ESP32 is powered via USB-C) |
| **Pin 2** | **SO (Serial Out)** | **GPIO 6** *(ESP32 SI)* | Data out from GB into ESP32 |
| **Pin 3** | **SI (Serial In)** | **GPIO 5** *(ESP32 SO)* | Data out from ESP32 into GB |
| **Pin 4** | **SD (Unused)** | *Do not connect (cut / insulate)* | Not used in trade protocol |
| **Pin 5** | **SCK (Clock)** | **GPIO 4** *(ESP32 CLK)* | Master clock generated by the GB (~8 kHz) |
| **Pin 6** | **GND (Ground)** | **GND** | **Mandatory Common Ground** between GB and ESP32 |

---

### 2. Step-by-Step Multimeter Continuity Guide

1. **Set Multimeter**: Turn your multimeter dial to **Continuity Test** mode (diode icon / audible buzzer). Touch the probes together to confirm the beep.
2. **Strip Outer Jacket**: Carefully remove 2–3 cm of the outer cable sleeve without cutting into the thin inner wires.
3. **Pin Mapping**:
   - Insert a thin pin or your multimeter probe into **Pin 6** of the front connector.
   - Touch each exposed wire end one by one until you hear a continuous beep (0 Ω).
   - **Write down the color corresponding to Pin 6 (GND)**.
   - Repeat this exact test for **Pin 5 (SCK / Clock)**, **Pin 2 (SO)**, and **Pin 3 (SI)**.
4. **Short Circuit Check (Critical)**:
   - Test continuity between all 4 identified wires against each other.
   - **No two wires should ever beep together**. If they beep, wires are touching or the cable is damaged internally.
5. **Unused Wires**: Cut or insulate Pin 1 and Pin 4 wires with heat-shrink tubing or electrical tape to prevent accidental shorts.

---

### 3. Soldering Procedure

1. **Pre-Tinning**: Lightly tin the stripped ends of the 4 wires and the ESP32-S3 SuperMini pads (**GND**, **GPIO 4**, **GPIO 5**, **GPIO 6**) with flux and solder.
2. **Solder Connections**:
   - Cable **Pin 6 (GND)** ➡️ Pad **GND**
   - Cable **Pin 5 (SCK)** ➡️ Pad **GPIO 4**
   - Cable **Pin 2 (SO)** ➡️ Pad **GPIO 6**
   - Cable **Pin 3 (SI)** ➡️ Pad **GPIO 5**
3. **Post-Soldering Inspection**:
   - Probe from the Game Boy front connector pin all the way to the soldered pad on the ESP32 board to verify a solid joint.
   - Check between adjacent pins (**GPIO 4**, **GPIO 5**, **GPIO 6**) with the multimeter to ensure no solder bridges exist.

> [!NOTE]
> **Logic Levels (5V vs 3.3V)**:  
> Game Boy operates at 5V logic while ESP32 is 3.3V. The Game Boy output signals into GPIO 4 and GPIO 6 are handled by the ESP32 internal clamping diodes for typical use, but for permanent builds a simple resistor divider (e.g. 1kΩ / 2kΩ) or a bidirectional 3.3V/5V logic level shifter is recommended. The ESP32 output (GPIO 5 at 3.3V) is recognized reliably as HIGH by the Game Boy.

## 🚦 RGB Status LED Diagnostics (GPIO 48)

The ESP32-S3 SuperMini features an addressable WS2812 RGB LED on **GPIO 48**. The firmware uses it for real-time link diagnostic feedback:

| LED Color | Engine Status | Meaning / Action |
|:---:|:---|:---|
| 🔴 **Red** | `STATUS_WAITING_GB` | ESP32 ready and Wi-Fi active. Waiting for Game Boy power or clock signal. |
| 🟡 **Amber / Yellow** | `STATUS_LINK_CONNECTED` | **Link detected!** 8 kHz handshake synchronized. *(Confirms GND, SCK, and SO are properly wired)*. |
| 🔵 **Blue** | `STATUS_IN_TRADE_ROOM` | Both players inside the Cable Club or seated at the trade table. |
| 🟣 **Purple / Magenta** | `STATUS_EXCHANGING_DATA` | Transferring trade block data or playing the trade animation. |
| 🟢 **Green** | `STATUS_TRADE_SUCCESS` | **Trade completed successfully!** Pokémon received and saved. |

## 📱 Quick Start Guide

1. **Power**: Connect the ESP32-S3 via USB-C to a power bank, charger, or PC. The RGB LED illuminates in **red**.
2. **Wi-Fi Connection**:
   - On your phone or PC, connect to Wi-Fi: **`GB-PokeTrader`** (no password).
   - The captive portal / sign-in screen opens automatically.
   - If not, navigate to: **`http://192.168.4.1`**.
3. **Configure Pokémon**:
   - Go to the **⚡ Send** tab, choose species, level, attacks, nickname, or click a preset (e.g. Gengar, Mew, Celebi).
   - In Gen II, choose **Shiny** status and a **Held Item**.
   - Click **💾 Cargar en la Mesa de Intercambio**.
4. **On your Game Boy**:
   - Plug the Link Cable into the console.
   - Start your game (R/B/Y or G/S/C) and enter the **Pokémon Center**.
   - Talk to the **Cable Club** attendant (Colosseum / Trade Center).
   - Save the game when prompted and enter the room.
   - Once both sit at the table, trading begins automatically.
5. **Receive and Modify**:
   - Once the trade finishes, the Pokémon received from the Game Boy appears in the **📥 Recibido** tab with its level, moves, and held item.
   - Modify any stats or attacks and click **📤 Preparar para Devolver a Game Boy** to trade it back.

## 🔌 Cableado, Identificación con Tester y Soldadura

> [!CAUTION]
> **¡NUNCA CONFÍES EN LOS COLORES DE LOS CABLES INTERNOS!**  
> Los cables Link de Game Boy de terceros (comprados en AliExpress, Amazon o tiendas retro) utilizan combinaciones de colores internas totalmente aleatorias según la fábrica o lote.  
> **Es obligatorio identificar cada cable con un multímetro (tester) en modo continuidad antes de soldar**.

### 1. Conector del Game Boy Link Cable

Mirando de frente el conector hembra o macho del cable Link:

```
       _____/-----\_____
      |  1     3     5  |
      |  2     4     6  |
      \_________________/
```

| Pin Conector GB | Nombre Señal | Conexión ESP32-S3 SuperMini | Función |
|:---:|:---:|:---:|:---|
| **Pin 1** | **VCC (+5V)** | *No conectar (cortar / aislar)* | Alimentación de la consola (el ESP32 se alimenta por USB-C) |
| **Pin 2** | **SO (Serial Out)** | **GPIO 6** *(SI del ESP32)* | Datos que salen de la GB y entran al ESP32 |
| **Pin 3** | **SI (Serial In)** | **GPIO 5** *(SO del ESP32)* | Datos que salen del ESP32 y entran a la GB |
| **Pin 4** | **SD (Sin uso)** | *No conectar (cortar / aislar)* | No utilizado en trades |
| **Pin 5** | **SCK (Clock)** | **GPIO 4** *(CLK del ESP32)* | Reloj maestro generado por la GB (~8 kHz) |
| **Pin 6** | **GND (Tierra)** | **GND** | **Tierra común obligatoria** entre la GB y el ESP32 |

---

### 2. Guía Paso a Paso con el Tester (Multímetro)

1. **Ajuste del Tester**: Pon el multímetro en la escala de **Continuidad** (icono de diodo / señal sonora de bip). Junta ambas puntas para confirmar que emite sonido.
2. **Pelado de la funda exterior**: Con cuidado de no cortar los hilos interiores, retira unos 2 a 3 cm de la funda plástica exterior del extremo del cable Link.
3. **Mapeo de Pines**:
   - Introduce una aguja fina o la punta fina del multímetro en el agujero del **Pin 6** del conector frontal.
   - Toca uno por uno los cables pelados con la otra punta hasta que el tester pite de forma continua (0 Ω).
   - **Anota el color encontrado para el Pin 6 (GND)**.
   - Repite el procedimiento con el **Pin 5 (SCK / Reloj)**, **Pin 2 (SO)** y **Pin 3 (SI)**.
4. **Verificación de Cortocircuitos (Muy Importante)**:
   - Prueba continuidad entre los 4 cables identificados entre sí.
   - **Ningún par de cables debe pitar entre sí**. Si pita alguno, hay hilos tocándose o el cable está dañado internamente.
5. **Cables sobrantes**: Los cables correspondientes al Pin 1 y Pin 4 córtalos o cúbrelos con cinta aislante / termorretráctil para evitar contactos accidentales.

---

### 3. Procedimiento de Soldadura

1. **Pre-estañado**: Aplica un punto pequeño de estaño y flux a las puntas peladas de los 4 cables y a los pads del ESP32-S3 SuperMini (**GND**, **GPIO 4**, **GPIO 5**, **GPIO 6**).
2. **Soldado**:
   - Cable del **Pin 6 (GND)** ➡️ Pad **GND**
   - Cable del **Pin 5 (SCK)** ➡️ Pad **GPIO 4**
   - Cable del **Pin 2 (SO)** ➡️ Pad **GPIO 6**
   - Cable del **Pin 3 (SI)** ➡️ Pad **GPIO 5**
3. **Inspección Final con Tester**:
   - Con el cable ya soldado, coloca una punta del multímetro en el conector frontal de la Game Boy y la otra directamente en el pin correspondiente de la placa ESP32. Debe pitar de inmediato.
   - Verifica que no haya puentes accidentales de estaño entre **GPIO 4**, **GPIO 5** y **GPIO 6**.

> [!NOTE]
> **Voltajes lógicos (5V vs 3.3V)**:  
> La Game Boy opera con niveles lógicos de 5V y el ESP32 a 3.3V. Las salidas de la Game Boy hacia los pines GPIO 4 y GPIO 6 son toleradas por las etapas de entrada del chip para pruebas habituales, pero para instalaciones permanentes se puede intercalar un divisor resistivo simple (ej. 1kΩ / 2kΩ) o un conversor de nivel lógico bidireccional de 3.3V/5V. La salida GPIO 5 (3.3V) es reconocida de forma nativa por la Game Boy como nivel alto (HIGH).

## 🚦 Diagnóstico Visual con LED RGB (GPIO 48)

El ESP32-S3 SuperMini cuenta con un LED direccionable WS2812 en el pin **GPIO 48**. El firmware lo utiliza para indicar el estado de la conexión en tiempo real:

| Color del LED | Estado del Motor | Significado / Acción |
|:---:|:---|:---|
| 🔴 **Rojo** | `STATUS_WAITING_GB` | ESP32 listo y Wi-Fi activo. Esperando que la Game Boy se encienda o genere señal de reloj. |
| 🟡 **Ámbar / Amarillo** | `STATUS_LINK_CONNECTED` | **¡Conexión detectada!** Handshake de 8 kHz sincronizado. *(Confirma que GND, SCK y SO están bien soldados)*. |
| 🔵 **Azul** | `STATUS_IN_TRADE_ROOM` | Ambos jugadores dentro del Club del Cable o sentados en la mesa de intercambio. |
| 🟣 **Púrpura / Magenta** | `STATUS_EXCHANGING_DATA` | Transfiriendo bloques de datos o reproduciendo la animación de intercambio. |
| 🟢 **Verde** | `STATUS_TRADE_SUCCESS` | **¡Intercambio completado con éxito!** Pokémon transferido correctamente. |

## 📱 Guía de Uso Rápido

1. **Alimentación**: Conecta el ESP32-S3 mediante su puerto USB-C a una batería portátil (powerbank), cargador o PC. El LED RGB se iluminará en **rojo**.
2. **Conexión Wi-Fi**:
   - En tu smartphone o portátil, conéctate a la red Wi-Fi: **`GB-PokeTrader`** (sin contraseña).
   - Se abrirá la ventana de bienvenida / portal cautivo automáticamente.
   - Si no se abre sola, entra en tu navegador a: **`http://192.168.4.1`**.
3. **Configura tu Pokémon**:
   - Ve a la pestaña **⚡ Enviar**, selecciona especie, nivel, ataques, mote o pulsa un preset (ej. Gengar, Mew, Celebi).
   - En Gen II puedes elegir si es **Shiny** y qué **Objeto Equipado** llevará.
   - Pulsa **💾 Cargar en la Mesa de Intercambio**.
4. **En tu Game Boy**:
   - Conecta el cable Link a la consola.
   - Enciende el juego (R/B/Y o G/S/C) y entra al **Centro Pokémon**.
   - Habla con la recepcionista del **Club del Cable** (Coliseo / Sala de Intercambio).
   - Guarda la partida cuando lo solicite y entra a la sala.
   - Al sentarte en la mesa, el intercambio comenzará automáticamente.
5. **Recepción y Modificación**:
   - Cuando termine el intercambio, el Pokémon que envió la Game Boy se mostrará en la pestaña **📥 Recibido** con su nivel, ataques y objeto.
   - Puedes cambiar sus estadísticas o ataques y pulsar **📤 Preparar para Devolver a Game Boy** para reenviárselo modificado.
